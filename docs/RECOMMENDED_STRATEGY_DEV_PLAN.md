## 1. 개요 및 추진 배경 🎯

### 1.1 배경 및 목적
- **시장 특성의 차이**: 암호화폐(업비트) 시장은 09:00 경주마/돌파 시간대, 12:00~18:00 오후 횡보장, 18:00 이후 미 증시 개장 변동성 등 시간대별로 뚜렷한 패턴 차이가 존재함.
- **운영자 중앙 제어 필요성**: 운영자가 각 시간대 장세에 최적화된 **'공식 골든 스탠다드 추천전략'**을 설정하고, 일반 사용자에게 실시간 배포할 수 있는 통합 관리 체계가 필요함.
- **기존 UI의 한계 극복**: 운영자 대시보드 모달(`OperatorDashboardModal`) 내에서 또다시 팝업을 띄우는 이중 모달 방식은 좁은 화면, 스크롤 피로도, 1~12번 슬롯 연계 설정의 어려움 등 치명적인 UX 문제를 야기함.

### 1.2 핵심 요구사항
1. **시간대별 3대 모드 분리**: `오전 모드 (PRESET_A)`, `오후 모드 (PRESET_B)`, `야간 모드 (PRESET_C)` 독립 설정
2. **UI 혁신**: 팝업 속 팝업 탈피 ➔ **대시보드 내부 와이드 캔버스 뷰 전환(Full Canvas Transition)** 채택
3. **완전한 파라미터 세트**:
   - 급등 포착 엔진 (Surge Engine)
   - 4대 리스크 방어 쉴드 (지지확인, VWAP, 쿨다운, 타임블록)
   - 트레일링 익절 & 손절 기준
   - 1~12번 슬롯별 권장 전략 모드 및 비중 매트릭스
4. **일반 사용자 연동**: 일반 사용자의 `PresetStrategyModal`과 실시간 동기화되어 원클릭 적용 지원

### 2.2 UI 인터랙션 세부사항
- **상단 세그먼트 탭**: `오전`, `오후`, `야간` 탭 클릭 시 깜빡임 없이 부드러운 전환(애니메이션).
- **2열 스플릿(2-Column Split)**:
  - 데스크톱/와이드 화면(1024px 이상): 좌측(엔진/방어설정 50%) + 우측(슬롯 매트릭스 50%) 나란히 배치.
  - 태블릿/모바일(1024px 미만): 세로 스택으로 자동 반응형 전환.
- **슬롯 일괄 제어 툴바**: 우측 상단에 "모든 슬롯 금액 일괄 변경", "전체 스캘핑/돌파 전환" 등의 퀵 액션 배치.

## 3. 데이터 모델 & 스키마 설계 💻

### 3.1 DB 테이블 구조 (`admin_strategy_presets`)
```sql
CREATE TABLE IF NOT EXISTS `admin_strategy_presets` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `mode_key` VARCHAR(20) NOT NULL UNIQUE COMMENT 'MORNING | AFTERNOON | NIGHT',
  `mode_name` VARCHAR(100) NOT NULL,
  `tag_text` VARCHAR(100) DEFAULT NULL,
  `description` TEXT DEFAULT NULL,
  `common_config` JSON NOT NULL COMMENT '급등포착, 방어쉴드, 트레일링 익/손절 파라미터 JSON',
  `slots_config` JSON NOT NULL COMMENT '1~12번 슬롯별 상세 설정 JSON',
  `updated_by` VARCHAR(50) DEFAULT 'admin',
  `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### 3.2 백엔드 API 명세
1. **GET `/api/admin/strategy-presets`**
   - 권한: 운영자(OPERATOR) 및 개발자(DEVELOPER)
   - 응답: 3개 모드(MORNING, AFTERNOON, NIGHT)의 전체 설정 반환
2. **POST `/api/admin/strategy-presets`**
   - 권한: 운영자/개발자
   - 바디: `{ modeKey: 'MORNING', commonConfig: {...}, slotsConfig: [...] }`
   - 기능: 해당 모드의 추천전략 저장 및 검증
3. **GET `/api/user/strategy-presets`**
   - 권한: 전체 회원
   - 응답: 일반 사용자가 `PresetStrategyModal`에서 선택 및 적용할 최신 공식 추천 프리셋 제공

## 6. 결론 및 기대효과 💖
- **쾌적한 관리 환경**: 팝업 속 팝업의 답답함을 완벽히 해소하고, 넓은 2열 캔버스에서 한눈에 전략을 튜닝할 수 있음.
- **장세 대응력 극대화**: 시장 변동성에 맞추어 오전, 오후, 야간 모드를 운영자가 유연하게 업데이트하고 회원들에게 원클릭 배포 가능.
- **안정적인 아키텍처**: 프론트엔드-백엔드-사용자 클라이언트 간의 데이터 싱크를 정규화하여 시스템 확장성 확보.
